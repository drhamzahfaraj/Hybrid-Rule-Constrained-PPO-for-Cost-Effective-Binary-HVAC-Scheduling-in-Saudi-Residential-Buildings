# Withdrawn pipeline (kept for the record)

Everything in this folder belongs to earlier versions of the manuscript and is
**not** the source of any figure in the current paper. It is kept, not deleted,
so that every claim the revision withdrew can still be traced to what produced
it.

What was withdrawn and why is set out in the manuscript itself (the paragraph
"Four withdrawals" in the Results, and the earlier-version notes throughout)
and in the response to the reviewers. In brief:

- the per-configuration cost table under three cost models, and its GA/SA
  comparators;
- the attribution of the largest saving to tier-boundary pre-cooling;
- the multi-zone per-zone cost scaling claim (now reported in Faraj 2026,
  JKSU-ES 38:58, for a different plant and band);
- the headline figures 18.2 % (Riyadh) / 16.8 % (Jeddah) under Model S, which
  rested on an hourly actuation interval the revision proves inadmissible;
- the `src/` package, which never imported (see `src/MISSING_MODULES.md`).

**The current code of record is `../../code/`.** Every number in the current
paper is mapped to its source file and generating script in
`../../VALUES_REGISTRY.md`.
