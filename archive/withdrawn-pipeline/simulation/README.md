# Simulation outputs

Data generated by `../reference_implementation/`. **Read the provenance note
before using these files.**

## Contents

| File | Description |
|---|---|
| `weather_daily_riyadh.csv` | Daily min/mean/max dry-bulb, mean GHI, CDD (base 22 °C), 365 days |
| `weather_daily_jeddah.csv` | As above for Jeddah |
| `trajectory_thermostat_riyadh_july_week.csv` | Hourly single-zone thermostat rollout, mid-July week |
| `trajectory_thermostat_jeddah_july_week.csv` | As above for Jeddah |

Trajectory columns: `hour`, `t_out_c`, `ghi_w_m2`, `t_zone_c` (zone temperature at
the start of the interval), `u_hvac` (0/1), `kwh`, `cost_sar`, `e_cum_kwh`
(cumulative monthly consumption driving the tariff tier), `cop`, `violations`.

## Provenance — two differences from the manuscript

**1. Weather source.** These files are derived from **TMYx (2009–2023)** typical
-year files, which are what this repository bundles. The manuscript's results
were produced with the older **IWEC** files (`SAU_Riyadh.404380_IWEC.epw`,
`SAU_Jeddah.410240_IWEC.epw`). The two datasets differ: computed from the bundled
TMYx files, cooling degree days (base 18 °C) are ~3,690 for Riyadh and ~4,260 for
Jeddah, whereas the manuscript quotes ~3,400 and ~2,900 from IWEC. Notably the
ordering differs — in TMYx, coastal Jeddah accumulates more cooling degree days
than Riyadh over the year (higher annual mean, 29.7 °C against 27.6 °C), even
though Riyadh has the hotter peaks (46.6 °C against 44.0 °C). Use the IWEC files
if you are trying to reproduce the manuscript.

**2. Model parameters.** The trajectories were generated at the reference
implementation's own parameters — effective thermal capacity 6,700 kJ/K and a
15-minute interval — **not** the manuscript's Table 2 values (air-mass capacity
77.2 kJ/K, 1-hour interval). Absolute costs therefore differ from the published
tables and should not be compared with them directly.

These files illustrate the modelled dynamics and the shape of a thermostat
schedule; they are **not** a reproduction of any published number.
